## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Chain Manager** | Save named Humanoid vocal processing chain configurations |
| **Session Presets** | Track active preset per session with project and artist notes |
| **Processing Notes** | Document vocal treatment decisions per track and session |
| **A/B Compare** | Log two chain configs for quick comparison in mixing sessions |
